ArkaB2B Hubs

Entrada única para herramientas de Swagger por servicio y flujos E2E.

Swagger

Hub por servicio

Tabs por microservicio con Swagger UI de IAM, Directory, Catalog, Inventory, Order, Notification y Reporting.
 E2E

Hub de pruebas E2E

Tabs por prueba funcional y transversal, con endpoints sugeridos agrupados por servicio y acceso directo al Swagger Viewer.

Tabs por servicio para abrir los reportes HTML de cobertura JaCoCo empaquetados por el gateway desde los builds locales.
